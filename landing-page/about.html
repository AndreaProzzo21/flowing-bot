About the lab

Systems that listen
before they act.

Based in Emilia Romagna, FlowingBot is a small automation lab working at the seam between physical devices and the cloud. We don't build dashboards for their own sake — we build the plumbing that makes the dashboard trustworthy.

How a signal moves through the lab

Sense. Transmit. Orchestrate. Observe.

Every system we ship follows the same four-stage path — it's the actual pipeline behind EdgeHub.

01 / SENSE

Edge instrumentation

Go and C++ agents read CPU, thermal, and vibration data directly off Raspberry Pi, ESP32, and bare-metal hosts — no polling a dashboard that's already stale.

02 / TRANSMIT

Reliable delivery

MQTT and stateless JWT pipelines move telemetry off-device, with over-the-air token rotation so a fleet never quietly drops offline.

03 / ORCHESTRATE

Cloud-native control

Kubernetes, GitOps, and zero-trust proxies turn raw ingestion into a system that scales — and that someone other than us can operate safely.

04 / OBSERVE

Decisions, not charts

Prometheus, Loki, and Grafana close the loop — the point isn't a pretty graph, it's catching the failure before it happens.

Vision

What we believe.

Workflows & Agents

True automation requires the right balance. We build robust, deterministic workflows to guarantee reliable core operations, and seamlessly integrate AI agents to handle dynamic contexts and complex edge cases.

IIoT is not optional

Hardware and software must speak the same language seamlessly. We treat sensors and physical machinery as the core foundation of our architectures, ensuring data integrity from the ground up.

Built to be operated

Long-term reliability is our priority. We engineer transparent, well-documented ecosystems designed to be easily managed, scaled, and sustained by your entire operations team.
